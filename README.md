# SpriteShip

**Create and refine the art for your 2D game.**

[Explore SpriteShip](https://spriteship.com) · [Sample games](https://github.com/spriteship/sample_games) · [Connect your coding agent](https://spriteship.com/agents)

SpriteShip brings AI game-asset generation, animation editing and map building into one workspace. Start with the asset you need, refine the result and export it for your game.

## What you can build

- **Characters and animations** — create characters, generate motions and choose the frames to keep.
- **Game artwork** — create props, backgrounds, tilesets, terrain and UI assets around your project’s art direction.
- **Manual refinements** — clean up unwanted pixels, adjust scale and position, and preview your animation edits.
- **Maps and scenes** — arrange your artwork in the visual map editor.
- **Agent workflows** — work with SpriteShip through MCP and the API from your coding agent.
